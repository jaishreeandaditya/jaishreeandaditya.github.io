Jaishree & Aditya - Wedding Invitation website
==============================================

What's in this folder
- index.html  : the whole invite (text, layout, RSVP, Lucknow guide)
- img/        : all the embroidered images
- audio/      : background music

Keep these three together exactly as they are. Do not rename the folders.

Putting it online (Netlify Drop - free, about 5 minutes)
1. Go to https://app.netlify.com/drop and sign up (Google sign-in is fine).
2. Unzip this file, then drag the whole "jaishree-aditya-invite" folder onto the page.
3. You get a live link like https://random-name-123.netlify.app
4. Site configuration > Change site name -> e.g. jaishree-aditya  (link becomes https://jaishree-aditya.netlify.app)

Updating later (same link stays)
- Netlify > your site > Deploys > drag the updated folder onto "Drag and drop your site output folder here".

Simple text edits yourself
- Open index.html in any text editor (Notepad / TextEdit in plain-text mode), use Find to locate the words, change them, save, and re-upload the folder.
